# SPEC: Payment Checkout

## Mô tả nghiệp vụ

Người dùng thanh toán đơn hàng qua cổng thanh toán bên thứ ba.

## Actors & Preconditions

| Actor | Mô tả |
|---|---|
| End User | Người dùng có giỏ hàng đã chọn sản phẩm |

## Happy Path

1. Người dùng vào trang Checkout.
2. Chọn phương thức thanh toán.
3. Xác nhận thanh toán.

> BA vẫn đang thu thập edge case, acceptance criteria, và bảng Screens — SPEC này CHƯA hoàn chỉnh, dùng để test trạng thái "done (chưa đầy đủ)".
