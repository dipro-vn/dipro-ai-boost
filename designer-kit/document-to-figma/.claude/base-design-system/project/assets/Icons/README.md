# Icons

Google Material Symbols as used by the Digital Agency design system (Apache License 2.0), exported from the source file at 24×24.

- Names end in the weight (`_300` light, `_400` regular), the fill (`_false` outlined, `_true` filled) or the size (`_large`, `_small`).
- Single-ink glyphs are drawn in `solid-gray-900` (#1a1a1a) as files; in components use `Icon`, which renders the same paths in `currentColor`.
- `checkbox_true`, `radiobutton_true`, `indeterminate_check_box_true` and the visibility pair carry `key-900` blue; `error_true` is a white glyph meant for a red ground.
- Use `new_window_300` after every link that opens a new tab, `arrow_right_300` for "go to" rows, `close_400` for dismiss buttons.
