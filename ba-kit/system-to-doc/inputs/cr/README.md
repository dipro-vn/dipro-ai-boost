# inputs/cr/ — yêu cầu thay đổi (Change Request)

Bỏ file yêu cầu của khách vào đây rồi chạy:

```
/change-request inputs/cr/<tên-file>
```

- Định dạng: `.docx` `.pdf` `.xlsx` `.md`, ảnh chụp màn hình.
- Mỗi CR 1 file (hoặc 1 folder con nếu có nhiều tệp đính kèm).
- AI lưu **nguyên văn** bản gốc vào `outputs/CR-<id>_<DDMMYY>_<slug>/input/` (ví dụ `outputs/CR-001_271026_them-coupon/input/`) — file ở đây có thể xoá sau.
